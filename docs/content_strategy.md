## 📝 Content Quality Guidelines

### Video Specifications

| Attribute | Requirement |
|-----------|-------------|
| Resolution | 1080p minimum (4K preferred) |
| Aspect Ratio | 9:16 (vertical) or 16:9 (horizontal) |
| Frame Rate | 24fps or 30fps |
| Bitrate | 5-10 Mbps |
| Codec | H.264 or H.265 |
| Audio | AAC, stereo, 128kbps minimum |

### Episode Structure

```
Ideal Episode Format (2-3 minutes):

0:00-0:10  - Hook / Previously on
0:10-0:30  - Scene setup
0:30-1:30  - Rising action
1:30-2:20  - Climax / Key moment
2:20-2:45  - Resolution or cliffhanger
2:45-3:00  - Next episode tease

Key Rules:
✓ Start with action or emotion
✓ End with cliffhanger
✓ One main storyline per episode
✓ Visual storytelling over dialogue
✓ Mobile-optimized framing
```

## 📈 Content Performance Analysis

### Key Content Metrics

| Metric | Definition | Good | Excellent |
|--------|------------|------|-----------|
| **Start Rate** | Users who start ep 1 | 30% | 50%+ |
| **Completion Rate** | Finish episode | 60% | 75%+ |
| **Binge Rate** | Watch 3+ eps in session | 40% | 60%+ |
| **Series Completion** | Finish all episodes | 20% | 35%+ |
| **Re-watch Rate** | Watch episode again | 5% | 10%+ |

### Content Scoring Algorithm

```python
Content Score = (
    0.3 × Completion_Rate +
    0.25 × Binge_Rate +
    0.2 × User_Rating +
    0.15 × Engagement_Rate +
    0.1 × Share_Rate
) × Recency_Multiplier
```

### Underperforming Content Actions

| Performance | Action |
|-------------|--------|
| <30% completion | Review and potentially remove |
| 30-50% completion | Optimize thumbnails/metadata |
| 50-70% completion | Monitor and learn |
| >70% completion | Feature prominently |

## 📆 Content Pipeline Workflow

```

├── Initial screening
├── Market fit analysis
└── Decision: Go/No-Go

├── Script review

├── Budget approval
└── Contract signing
```
