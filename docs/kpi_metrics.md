# Kona KPI & Metrics Dashboard
## Key Performance Indicators for Success

---

## 📊 Metrics Framework

### North Star Metric

**Weekly Active Viewers (WAV)**
> Users who watched at least one episode in the past 7 days

**Why:** Combines acquisition, engagement, and retention into one metric that correlates with revenue.

## 🔔 Alert Thresholds

### Critical Alerts (Immediate)

| Metric | Threshold | Action |
|--------|-----------|--------|
| Error Rate | >5% | Page engineering |
| Payment Failures | >10% | Page finance + eng |
| DAU Drop | >30% day-over-day | Investigate immediately |
| API Latency | >2 seconds | Page DevOps |

### Warning Alerts (Within 4 hours)

| Metric | Threshold | Action |
|--------|-----------|--------|
| D1 Retention | <40% | Product review |
| Conversion Rate | <5% | Growth review |
| Churn Spike | >15% week-over-week | Retention review |
| Support Tickets | >100/day | Support escalation |
